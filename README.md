# Taqwim — Islamic Calendar

A beautifully crafted Islamic (Hijri) calendar app for iOS and Android. This repository hosts the app's public privacy policy and support pages.

## Features

### Calendar
- **Lunar Cycle Arc** — Interactive draggable arc showing moon phase progression through the month with milestone markers
- **Accurate Moon Rendering** — Real-time moon phase visualization with illumination, terminator shadow, mare details, and pulsing ambient glow
- **Hijri Calendar Grid** — Full month view with event indicators, sunnah fasting dots, and Friday highlighting
- **Multiple Calculation Methods** — Umm al-Qura, Islamic Civil, and Islamic Tabular calendars
- **Manual Hijri Adjustment** — Fine-tune dates by ±2 days for local moon sighting differences
- **Gregorian Date Overlay** — Optional display of corresponding Gregorian dates
- **Post-Maghrib Date Adjustment** — Islamic day advances automatically after sunset

### Prayer Times
- **6 Daily Prayers** — Fajr, Sunrise, Dhuhr, Asr, Maghrib, and Isha
- **12 Calculation Methods** — Muslim World League, ISNA, Umm al-Qura, Egyptian, and more
- **2 Madhab Options** — Shafi'i/Maliki/Hanbali or Hanafi for Asr calculation
- **Location-Based** — Automatic calculation using device location

### Islamic Events
- **30+ Events** — Eid al-Fitr, Eid al-Adha, Ramadan, Laylat al-Qadr, Isra & Mi'raj, and more
- **Color-Coded Categories** — Eid, Hajj, Ramadan, Holiday, Fasting, and Historical
- **Sunnah Fasting Detection** — Monday/Thursday fasts, Ayyam al-Beed, Day of Arafah, Six Days of Shawwal
- **Fasting Guide** — Dedicated section explaining key fasting periods
- **Calendar Sync** — Sync Islamic events to your device calendar

### Widgets
- **Home Screen Widget** — Hijri date and moon phase at a glance
- **Lock Screen Widget** — Compact circular widget for the lock screen (iOS)
- **Prayer Times Widget** — Today's prayer times with the current prayer highlighted
